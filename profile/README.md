# MCP Projects

*A little home for my MCP projects.*

A personal collection of MCP servers, integrations, and experiments — built to connect various services with AI-powered tools.

Each project lives in its own repository, with its own documentation and setup instructions.

### Acknowledgements

Huge thanks to those who pioneered the reverse engineering of the services and protocols behind these projects, saving me from burning AI brainpower on the basics.

Their work makes it possible to spend more time building things rather than rediscovering how everything works.

### Projects

Explore the repositories in this organization to find individual MCP servers, integrations, and their documentation.

| Project | Description |
| --- | --- |
| [MailBridge](https://github.com/Kfjie-MCP/mailbridge) | Multi-account email search, reading, attachments, and management over MCP. |
| [Momo](https://github.com/Kfjie-MCP/momo) | MaiMemo study progress, review queues, vocabulary, and Markji cards. |
| [Transcriptor](https://github.com/Kfjie-MCP/transcriptor) | Video metadata, subtitles, transcription, and frames for AI tools. |
| [Agent Reach](https://github.com/Kfjie-MCP/agent-reach) | Read-only search and content retrieval across public platforms. |
| [Xuexitong](https://github.com/Kfjie-MCP/xuexitong-cli) | Course information, chapter resources, and original course files. |
| [MCP Auth UI](https://github.com/Kfjie-MCP/auth-ui) | Shared OAuth authorization pages for these MCP services. |

Contributions, suggestions, and improvements are welcome.
